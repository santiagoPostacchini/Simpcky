Política de firma de código

Las versiones firmadas de Simpcky usan firma de código gratuita provista por SignPath.io, con certificado de SignPath Foundation. Las versiones hasta la 0.3.0 no están firmadas.

Qué se firma

Solo los programas que GitHub Actions compila, en los servidores de GitHub, a partir del código de este repositorio público: simpcky.exe y su instalador Simpcky-Setup-X.Y.Z.exe. Nada que no salga de ese código se firma con este certificado. Cada pedido de firma lo aprueba a mano una de las personas de la lista de aprobadores.

Privacidad

Simpcky no envía información a otros sistemas salvo que quien lo usa lo pida. Se conecta a internet solo para dos cosas, las dos avisadas y con su interruptor:

  • Sincronizar con Google Drive, solo si conectás tu cuenta de Google.
  • Buscar actualizaciones en GitHub una vez por día. Se puede apagar en la pantalla de bienvenida o en el menú de la bandeja.

Todos los detalles: política de privacidad.

Code signing policy

Signed releases of Simpcky use free code signing provided by SignPath.io, certificate by SignPath Foundation. Releases up to 0.3.0 are not signed.

What gets signed

Only the programs built by GitHub Actions, on GitHub-hosted runners, from the source code in this public repository: simpcky.exe and its installer Simpcky-Setup-X.Y.Z.exe. Nothing that is not built from that source is signed with this certificate. Every signing request is manually approved by an approver listed below.

Team roles and their members

  • Committers and reviewers: Santiago Postacchini
  • Approvers: Santiago Postacchini

All team members use multi-factor authentication on GitHub and SignPath.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. It connects to the internet only to sync notes with Google Drive (only if the user connects their Google account) and to check GitHub for updates once a day (can be turned off in the welcome screen or the tray menu). See the full privacy policy.
